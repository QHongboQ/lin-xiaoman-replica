# 配置示例

`runtime/` 包含当前运行实例的 19 份插件配置副本和 AstrBot 命令配置，已将令牌、凭据、用户/群标识、白名单、服务地址和本机路径清空或替换。它们按插件当前版本整理，可在首次部署时作为初始配置；启用前请填入你自己的管理员、会话、模型服务和令牌。配置字段会随插件版本变化，若市场安装了不同版本，请先让插件生成配置，再对照这些示例迁移设置。

AstrBot 的模型提供方凭据和 QQ 连接器配置需要在管理面板重新建立；模板不包含 `data_v4.db`。其他私有设置包括 Airi Gallery 上传和同步令牌、MusicDL Cookie（可选）、管理员 UID、白名单及会话目标。将这些写入本机 `data/config/` 或环境变量，绝不要提交到 GitHub。

可以公开共享的设置是插件职责、图库分类名（`林小满`）、浏览命令模式、模型行为说明、时区规则等非凭据选项，见 [`settings.md`](../docs/settings.md)。
