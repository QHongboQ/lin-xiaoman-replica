# 林小满手动制图素材包

机器人收到照片请求后只从已上传图库随机发图，不再调用文生图、改图、参考图、动态穿搭或姿势规划。两轮拉扯保留：第一次索要时由小满拒绝，短时间内第二次继续索要才从本地图库挑一张当天尚未发过的照片。

本素材包供你在图片平台手动制作并上传图库。每张图片建议使用同一份「固定外观」，再各选一条「场景」「穿搭」「姿势」和表情细节，避免批量图片复制同一构图。

## 文件

- `固定外观提示词.txt`：小满的静态长相与真人手机摄影质感。
- `姿势库_160.json`：原有 160 条动作姿势，保留作手动选姿势素材。
- `场景地点库.md`：常见地点、环境层次、光线和可见物件。
- `裙装穿搭库.md`：30 套偏年轻、日常、以裙子和连衣裙为主的穿搭。
- `组合提示词示例.md`：20 条可以直接复制的完整动态段。每次和固定外观提示词拼接使用。
- `外观静态锚点_源.json`：当前插件里的原始静态外观资料备份；后续换发型或审美时可编辑自己的副本。

建议一次生成一张。场景提示词要写出画面里能看见的证据，例如书架、店招、桌面画册、夜间灯牌、雨水反光；不要只写地点名。姿势应轮换坐、站、行走、回头、镜面自拍和环境互动。衣服、发型、头饰、表情也轮换，避免连续图片像同一张照片换背景。
