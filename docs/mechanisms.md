# 林小满运行机制说明

本文按公开仓库所依据的 2026-10-06 WSL 运行配置、插件源码快照和人格卡整理。它描述的是一套由 AstrBot、多个插件、模型和本地运行数据共同组成的系统，不是一个单独的“林小满程序”。不同部署的插件版本或设置不同时，行为会变化。下文用“当前配置”标记从本仓库脱敏配置确认的内容，用“取决于模型/部署”标记不能保证每次触发的能力。

## 1. 总体消息链路

```text
QQ / 其他平台消息
  → AstrBot 接收、会话与平台适配
  → 消息防抖（短时间连续消息合并、媒体/引用/链接预处理）
  → 天使之心判断是否进入当前对话、是否需要回应
  → 安全检查、记忆/关系/时间/日程等上下文注入
  → 主模型依据人格卡生成回复，并按需调用图片、记忆或语音工具
  → 分段/媒体发送/输出检查
  → 平台发送；记忆、学习、关系和运行状态写入本机数据
```

这是一张逻辑图，不代表每个插件都以固定的先后顺序运行。AstrBot 的事件优先级、插件配置和模型工具调用会影响具体路径。好感度、记忆、日程、图片库及登录状态都是运行时数据；公开仓库不会携带原实例数据库。

## 2. 人格与对话边界

人格基线见 [`persona.md`](persona.md)。林小满被设定为 16 岁高一美术特长生：熟人面前嘴硬、好胜、爱接梗，越在意越不愿直接示弱；陌生人或严肃问题面前收敛。模型应先回应对方正在谈的事，再决定是否调侃，短句为主；不确定时承认不确定。

人格卡还规定了隐私和关系边界：不提供可定位的住址、学校和家庭信息；不牵扯家人、不骂脏话、不持续攻击真实痛处；不写露骨或性内容、不表白、不把关系最终定性。严重现实问题应暂停玩笑，认真回答。人格是系统提示词约束，不是硬编码状态机；最终措辞仍由模型生成，需配合内容安全审核。

## 3. 群聊在场与回复节奏

- **天使之心（Angel Heart）**负责群聊参与门控和回复节奏。当前配置启用了“被提及才进场”和“被明确召唤时强制回复”等唤醒选项，并有群聊增强、回声回复与输出清理设置。
- 插件说明包含前台、秘书、助理的分工：整理事件/账本，评估是否接话，再由主模型生成内容。轻量判断是否启用以及实际阈值由该插件配置决定，不能据此保证每条群消息都会回应。
- **消息防抖动**会在短窗口内合并连续私聊消息，支持群聊防抖、输入状态、引用/合并转发、图片保留、QQ 卡片和链接解析等处理。目标是把“等一下”“还有一张图”等连续输入作为一个上下文，而不是触发多轮回复。
- **Splitter**按语义拆分较长回复，避免一条消息过长；当前模板启用了智能分段、群聊分段与媒体引用回复相关选项。它只改变发送形态，不负责决定回复内容。

## 4. 关系、记忆和学习

这些能力相互配合，但职责并不相同：

### 天使之魂（Angel Memory）

- 按会话/用户检索长期记忆，并可使用本地 embedding 检索。
- 已启用灵魂状态相关能力；后台整理记忆，避免把完整聊天记录都塞进每次提示词。
- 给模型提供 `angel_remember`、`angel_recall`、`angel_note_read`、`angel_note_create` 等记忆/笔记工具。模型可以主动记住、回忆或整理信息，但何时调用由模型和工具策略决定。

### 自主学习（Self Learning）

- 当前模板开启了消息采集、自动学习、表达风格与群聊黑话学习、每日情绪/好感度能力、关系上下文注入及夜间编排等选项。
- 好感度按用户关系变化，并存在阶段、情绪和时间衰减等动态机制；不会因为对所有人说同一套话而固定不变。具体数值与阶段保存在本地数据库，重建实例后从空状态开始。
- 学习结果经过插件的审核/整理逻辑后进入可注入的人格或关系上下文；不要把它理解成模型权重训练，也不要把自动学习当作永不出错的事实来源。
- 当前配置含原始消息保存相关选项。运行者应在插件面板检查保留期限、备份和用户告知，并确保日志/数据库不公开。

### 羽笔（QuillPlus）

- 当前配置启用了世界书、写作素材、RAG/本地向量检索、自主反思、聊天记录和状态栏等模块。
- 适合放置稳定设定、背景材料和可检索文档；与 Angel Memory 的个人记忆、Self Learning 的关系/风格学习不是同一份数据。
- 多套记忆与 RAG 同时开启可能重复注入或产生冲突。迁移/改配置时要明确每类内容的唯一来源，并在 AstrBot 面板检查实际注入结果。

记忆与关系属于本地私有状态，上传 GitHub 的只有脱敏配置模板和源码，不包括聊天、好感度、笔记或向量库。

## 5. 时间、日程与生活状态

- **拟人化生活日程（Life Scheduler）**按日期、节日、历史日程和近期对话生成当天计划/穿搭，并将当前活动等信息注入提示词；可用衣柜条目、图片和管理员修改来约束计划。日程未准备好时可能在首次对话时懒加载生成。
- **TimeAwareness（时笺）**提供真实时间、上次聊天间隔、工作日/农历/节气/节日等时间传感器，以及按人格生成的日历和单日日程。动态时间内容按临时上下文注入，避免将每次变化写入聊天历史。
- 两个日程插件的能力有重叠：前者侧重每日穿搭/活动叙事，后者侧重时间事实、静态时段和日历。部署时需检查时区、地点锚点、人格日程和静态日程，避免同一时间给模型互相矛盾的活动。
- **大肥鱼钱包保卫战**按配置时区及供应商峰谷时段控制模型服务调用，并可播报状态、提醒或汇总事件。启用后，在受控时段机器人可能不回答；这是成本闸门，不是模型故障。
- **Scheduled Sender**支持一次性、每日、工作日、间隔与 Cron 任务，并可在单项任务里轮换多条候选消息。时区和调度规则是配置，具体任务及目标会话保存在本地 `plugin_data`，本仓库不携带原设备任务。新部署时须从零创建并核对接收对象。

日程生成内容是模型辅助的角色状态，不应被当作现实行踪；人格卡禁止输出精确住址、学校或家庭定位信息。

## 6. 图片与图库：三条不同路径

### 林小满角色照片

- 仓库的 `gallery/xiaoman/` 是 Airi Gallery 中“林小满”分类的 37 张静态图片。
- Airi Gallery 当前配置启用 LLM 工具。个人接口提供 `send_xiaoman_photo()`，只有主模型根据人格/上下文决定发图时才调用；接口再委托 Airi 的 `gallery_send`，限定“林小满”分类、一次 1 张。
- Airi Gallery 还提供分类/别名管理、按序号或范围浏览、上传、重复检测、删除、图库重建/同步及 Web 管理等维护能力；需按安装版本帮助操作，并将上传令牌、Git 凭据和管理员权限留在本机。远程同步只在完成私有凭据配置后可用。
- 未确认工具成功时不应声称已发送。自然聊天提到“照片”并不等于必须发图；显式浏览命令由图库插件处理（例如 `/看看小满`，实际命令前缀遵循 Airi 设置）。

### 表情包和群聊斗图

- **Smart ImageChat Hub**管理单独的表情包/反应图图库，支持语义检索、用户搜索后回复、主动表情、斗图模式、图像标签、图片导入、自动采集与备份。
- 当前配置启用了主动表情、自动采集相关功能和定期备份。自动采集可能把对话中的图片带入待审核/图库流程；管理员应检查采集规则、排除内容与图库容量。机器人自己的林小满照片不应混入表情包池。
- **画境拾珍（Get PX）**是另一路插画检索/签到插件，可按标签检索外部插画源，并提供签到及群排行等功能。它不是林小满图库，不会替代角色照片接口；外部图片的来源、过滤和发送受其配置及服务可用性限制。

三路内容要区分：`林小满图库 = 角色照片`，`Smart ImageChat = 表情包`，`Get PX = 外部插画/签到`。

## 7. 语音、音乐与多媒体

- **TTS Emotion Router**支持按需 TTS 工具、情绪路由、文字/语音策略及分段/概率输出；当前配置开启了语音相关策略和 LLM 工具。是否实际发语音取决于策略、会话名单、TTS 服务凭据和模型选择，不应假定每条文字都会配语音。
- **MusicDL**支持多音源搜索、结果分页、换源、下载及以语音/群文件发送；**Music Pro**是另一套点歌接口。它们与 TTS 的“朗读角色回复”是不同功能，音源可用性和版权由部署者负责。
- **连续消息解析**还会处理图片/引用/合并转发、卡片与链接等输入；是否得到图像理解结果取决于平台媒体权限及已配置的多模态模型。
- **Essential**是独立的娱乐/实用工具插件，不是核心人格或必需兼容层。上游 v1.1.0 提供搜番（图片识番）、随机动漫图片、喜报/悲报图片生成、Minecraft 服务器状态、一言、今日吃什么及候选列表、Epic 喜加一信息，以及早安/晚安时间与群统计等功能。命令名、外部 API 和可用性以部署版本 README 为准；这些工具的外部访问与副作用应在测试会话检查。

## 8. 安全、审核、成本与管理

- **阿瓦隆内容安全守卫**当前配置启用了输入和输出检查、关键词规则、LLM 审核、重复回复拦截及群聊相关限制。审核可能拒绝输入或屏蔽模型输出；必要时会按模板发送占位回复。
- 管理员/白名单、命令权限和会话范围应全部换成复刻者自己的账号。个人接口的 `/xiaoman_test` 受 AstrBot 管理员权限限制；测试模式绕过仅对被启用的当前会话生效。
- AstrBot 基础扩展提供 `/help`、`/sid`、`/stop`、`/reset`、`/new` 等核心管理/会话命令；扩展插件另提供模型、插件、历史和管理员管理命令。危险管理命令仅授予可信管理员。
- **Cost Control**上游基线提供按会话/用户/模型/全局日/月维度的 token 与费用预算，可配置预警、停止或回退动作，并提供价格规则、缓存诊断、用量归因、Web 面板和报告/诊断命令（如 `/cost`、`/budget`、`/cache`、`/report`）。不少策略存于插件私有 `plugin_data` 配置，仓库模板只有启用开关。本机 0.4.1 基于上游 `2b53332` 且有 4 个本地源码改动未分发；上游行为是参考基线，新机不能精确复刻本机改版或其私有策略。

## 9. 哪些行为不是确定性保证

1. 人格、情绪、是否接话、是否使用记忆工具、是否主动发图片/语音，通常由模型结合提示词和工具策略判断，可能因模型版本、采样参数和上下文而异。
2. 自动学习、情绪/好感度结算、定时播报、图库采集和定期备份依赖插件启用、调度器运行、目标会话、模型或外部服务可用。
3. 本仓库保存的是按当前 WSL 版本整理的源码快照和已脱敏配置，不包含登录态、运行数据库、定时任务状态、插件内部图库/缓存或五个未随仓库分发的插件源码。
4. 具体选项与版本以 [`plugin-lock.md`](plugin-lock.md)、[`configs/runtime/`](../configs/runtime/) 和部署后的 AstrBot 插件配置页为准。

## 11. 复刻后建议验收

- 在群聊中分别测试未提及、明确提及和管理员命令，确认在场门控及权限符合预期。
- 连发几条私聊文字/图片，确认防抖合并、引用和媒体上下文正常。
- 测试不同用户的记忆隔离、记忆工具调用和好感度阶段；不要用真实私人数据做公开演示。
- 检查每日计划、当前活动、时区、节假日、峰谷闸门和定时消息目标，确认没有冲突或错误收件人。
- 分别测试林小满照片、表情包搜索/主动表情、外部插画检索，确认图源没有混库。
- 明确请求语音并验证 TTS 凭据；测试安全拦截、群聊命令权限和管理员权限。
- 重启后确认配置持久化，并确认数据库、记忆、群号、账号令牌仍只保存在本机。
