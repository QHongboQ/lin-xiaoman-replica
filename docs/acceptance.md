# 全功能验收清单

这份清单用于新机器初始化完成后逐项验收。建议只在自己的测试私聊/测试群和测试账号上进行，避免在真实群里测试自动发图、语音、签到、定时消息或拦截功能。验收前确认所有需要手动安装的插件已就绪，配置与 [`plugin-lock.md`](plugin-lock.md) 对应。

状态栏可自行记录：`[ ] 未测` / `[x] 通过` / `[!] 失败或未配置`。下表说明预期行为，不会替代实际测试。

| 项目 | 操作 | 通过标准 | 前置条件 / 注意事项 |
|---|---|---|---|
| Docker 与数据目录 | `docker compose --env-file deployment/.env -f deployment/compose.yaml ps`；打开本机 AstrBot 面板 | AstrBot 容器健康运行，数据挂载到 `deployment/runtime-data/`，重启后仍存在 | Docker Compose v2；不要公开该目录 |
| 插件加载 | 在插件管理页面查看所有 21 项并检查启动日志 | 随仓库插件已加载；五个未随包插件已独立安装；无导入错误或依赖错误 | 版本参考 `plugin-lock.md`；缺少插件本身不应被误当作完整通过 |
| 全局身份与权限 | 查看 AstrBot Provider、模型、平台连接器、管理员 | 使用自己的账号/密钥；普通成员不能执行管理命令 | 真实 Provider/QQ 凭据不在仓库 |
| 人格边界 | 测正常闲聊、真诚夸奖、身高/数学玩笑、严肃求助、隐私诱导 | 语气符合 `persona.md`；严肃问题收敛；不输出精确学校/住址/家庭定位信息 | 模型输出存在概率性，应多轮抽测并配合安全插件 |
| 私聊连续输入 | 在防抖窗口内分多条发送一段话，再尝试图片/引用/链接 | 合并为一轮上下文，没有重复触发多次回答；保留允许的媒体/引用信息 | 检查防抖窗口、输入状态和平台适配能力 |
| 群聊在场门控 | 测试未提及、提及机器人、明确召唤、回复机器人；另测长时间活跃对话 | 按天使之心配置参与；被明确召唤时按预期回复，普通无关消息不会被承诺必答 | 群聊增强开关、提及识别和轻量判断模型需已配置 |
| 输出压缩与分段 | 发一条需要较长解释的问题 | 回复长度遵守配置；过长内容按语义拆分、没有截断词句/媒体引用失效 | 检查 Angel Heart 长度策略与 Splitter 设置 |
| 记忆写入与回忆 | 在测试用户私聊告诉机器人一个无敏感测试事实；明确让它记住，再隔一段对话询问 | 记忆工具按需写入，后续仅对正确用户检索，不串到另一用户或群 | Angel Memory embedding/范围配置；插件需具备存储写权限 |
| 笔记工具 | 请求整理一段虚构测试材料为笔记，再让模型查询/分页读取 | 笔记工具可用，结果能被召回；不把未验证的模型总结当客观事实 | 检查 note assistant 的 recall/create 开关 |
| 好感度与关系 | 在测试会话查看 `/好感度`，用几轮友好/冷淡交互后复核 | 关系状态按用户隔离；阶段/变化遵循本地插件设置 | Self Learning 命令权限和状态库；不要直接篡改生产库 |
| 学习审核与备份 | 执行 `/learning_status`，让测试群产生少量虚构黑话/风格样本；查看审核/备份页面 | 采集范围正确；学习结果可审核/回滚/备份，测试数据不会污染正式人格 | 模板启用了消息采集/自动学习；确认日志保留合规 |
| 世界书与 RAG | 在测试知识库加入一段虚构内容，再提问并检查检索结果 | 仅命中对应知识库/世界书，未与用户私有记忆混淆 | 羽笔 Provider、embedding、集合 ID 和权限 |
| 每日生活日程 | 查看 Life Scheduler 的今日计划/衣柜，触发新日期或管理员重写 | 今日衣着与活动能进入模型上下文，地点保持公开粒度且无互相矛盾行程 | 日期、地点锚点、衣柜、模型 ID；状态是本机数据 |
| 时间感知与日历 | 询问当前时段、工作日/节气/节日和上次聊天间隔 | 时间与部署时区一致；静态/AI 日历内容合理；不把临时状态写成长期事实 | 系统时区、TimeAwareness 与 Life Scheduler 配置 |
| 峰谷成本闸门 | 在测试环境查看 `/峰谷`；若要验证暂停/恢复，使用短暂测试时段和测试 Provider | 时段状态符合时区/星期配置；恢复时能再次调用模型；管理员绕过范围正确 | 可能中止模型调用，禁止在生产时段盲目切换 |
| 林小满角色照片 | 请模型在合适的测试对话中发送照片，检查 Airi 工具调用和收到的图片 | 只从 `林小满` 分类委托发送 1 张；工具失败时不谎称发送成功 | Airi `llm_tool_enabled`、gallery_send、导入图库；本测试涉及实际发图 |
| 显式图库浏览 | 输入 `/看看小满`、`/看看默认` 或 Airi 提供的其它浏览命令 | 命令被 Airi 接管；普通文本 `看看小满` 仍由 LLM 正常处理 | `view_command_mode=prefix`；不同版本命令可能有差异 |
| 图库维护与权限 | 在私有测试分类创建/上传测试图，检查重复检测、索引/同步，再按帮助删除测试图 | 管理命令仅授权给可信管理员；重复图有预期提示；删除和远程同步均作用于正确分类/仓库 | 先用无价值测试图；勿将真实 Token 写入仓库；远程 Git/云图库需单独配置 |
| 表情搜索和斗图 | 在测试图库中请求搜图/表情，验证主动表情与斗图策略 | 只从 Smart ImageChat 表情图库检索，不误用角色照片；匹配失败有清楚退路 | 表情标签已构建；主动表情阈值、UMO 范围等已设置 |
| 自动图片采集与备份 | 在测试群发送允许采集的自制图，再查看待审核/图库和备份页面 | 采集规则按配置工作；不收机器人自己发的照片或敏感图；备份位置/保留可控 | 自动采集可能改变图库，先用测试目录且准备好清理流程 |
| Get PX 插画与签到 | 用 `/p` 测试受控插画检索；用 `/签到`、`/签到帮助` 查看签到功能 | 外部插画与安全过滤按设置工作；签到仅写入新实例自己的数据 | 需外部服务可访问；注意平台/服务条款与群规则 |
| TTS 语音 | 查看 `/tts_status`；在测试会话用 `/tts_say` 明确请求语音，再分别测试启用/停用策略 | 音色/情绪映射可用，语音文件发送成功，未授权会话不会被意外自动播报 | 服务商密钥、音色和自动语音范围；发送真实语音需测试群 |
| MusicDL 点歌 | `/music_help` 查看帮助；在测试群搜索歌曲、分页、换源，再取消一次 | 搜索、下载和发送方式符合设置；无 Cookie/音源权限时返回合理失败 | 外部音源稳定性/版权不由仓库保证；检查下载空间 |
| Music Pro 点歌 | 用 `/点歌` 搜索一首可公开试听的曲目 | 服务 URL/API/音质设置生效；失败不影响普通聊天 | API 服务可用性和使用条款 |
| Essential 工具 | 在私有测试会话逐项查看帮助并试用 `/搜番`、`/moe`、`/喜报`、`/悲报`、`/mcs`、`/一言`、`/今天吃什么`、`/早安`、`/晚安`、`/喜加一` | 已配置的功能正常返回；外部服务失败有合理提示；早晚安统计写入预期的新实例数据 | 命令及依赖随版本变化；图片识别/外部 HTTP/群统计仅在测试账号使用 |
| Cost Control 预算与报告 | 在测试 Provider/小额预算环境查看 Web 面板，核对 `/cost`、`/budget`、`/cache`、`/report`；尝试预警策略 | token/费用累计与价格规则合理；预警/回退动作符合设定，状态解释清楚 | 很多配置存于私有 `plugin_data`；先使用 warn，勿用生产调用测试 stop；本机改版与上游不同 |
| 定时发送 | 在测试群建立单次、短周期及候选消息轮换任务，用 `/定时 测试` 验证并删除 | 仅发给指定测试会话；时区、重复计划、轮换和错过任务策略正确 | 不从原机复制任务；上线前再次核对目标 ID；检查插件帮助中的 Cron 语法 |
| 安全拦截 | 在测试环境输入安全插件文档中的无害测试样例或配置关键词 | 输入/输出审核按预期拦截并给出设置中的提示；不过度拦正常内容 | 不要使用真实恶意 payload 或生产群；检查白名单绕过范围 |
| 管理命令与测试模式 | 管理员运行 `/xiaoman_test status`、`on`、`off`；普通用户尝试该命令 | 仅管理员可控；仅当前 UMO 开启测试绕过；重启后模式关闭 | `/xiaoman_test` 有意提高测试优先级，只能留在测试私聊/群 |
| AstrBot 基础命令 | 测 `/help`、`/sid`；在测试会话按需测试 `/new`、`/reset`、`/stop` | 命令执行目标会话正确，管理员命令权限符合预期 | `/reset` 会影响当前会话上下文，只在测试会话运行 |
| 数据持久化与备份 | 重启 AstrBot；检查容器、插件、图库与配置仍在；制作一份加密离线备份 | 重启后能恢复；备份包含必要私有数据但不进入公开 Git | 参考 `restore-and-backup.md`；定期实际演练恢复而不只检查备份存在 |
